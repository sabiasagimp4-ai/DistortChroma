DistortChroma  
製作者：panko200  
配布場所：https://github.com/sabiasagimp4-ai/DistortChroma/releases

## 概要

YukkuriMovieMaker4 にて動作する映像エフェクトプラグインです。  
色ズレありVectorBlurらしいです。

## インストール方法

1. [Releases](https://github.com/sabiasagimp4-ai/DistortChroma/releases) から最新の `DistortChroma_vX.X.X.ymme` をダウンロードする。
2. YMM4 を終了してから、`.ymme` ファイルをダブルクリックしてインストールする。

手動でインストールする場合は、`DistortChroma_vX.X.X.zip` を展開し、中の `DistortChroma` フォルダを YMM4 の `user\plugin` フォルダに入れてください。

## 使用方法

1. プラグインをインストールして YMM4 を起動する。
2. アイテムを追加し、映像エフェクトの「加工」から「DistortChroma」を適用する。
3. 任意の設定にすれば、動きます。

### 参照値（マップ）

歪みの方向を、マップの何の変化から計算するかを選びます。

- **輝度**（初期値）：明るさの変化に沿って色ズレします（従来と同じ）。
- **不透明度**：透明な部分との境目（形の輪郭）だけに沿って色ズレします。模様や色の違いがあるアイテムでも、輪郭だけにきれいに収差を付けたいときに便利です。

### 基準位置

色ズレをどこを基準に広げるかを指定します。

- **0%**（初期値）：元の位置から歪みの方向の片側へずれます（従来と同じ）。
- **50%**：元の位置を中心に両側へ広がるので、全体の位置がずれません。
- **100%**：歪みと逆の方向の片側へずれます。

### 色（収差の色の指定）

歪み量 0 の側から歪み最大の側へ向かって、指定した色相の範囲で色が割り当てられます。

- **色相**：開始色（歪み 0 の側の色）。0 で赤、120 で緑、240 で青。
- **色相範囲**：開始色から歪み最大側の色までの色相の幅。マイナスで逆回り。

| 色相 | 色相範囲 | 色の並び（歪み 0 → 最大） |
| --- | --- | --- |
| 0 | 240 | 赤→黄→緑→水色→青（従来と同じ、初期値） |
| 0 | 360 | 赤→…→青→紫→赤（虹色一周） |
| 300 | 180 | マゼンタ→赤→黄→緑 |
| 30 | 180 | オレンジ→黄→緑→水色 |
| 240 | -240 | 青→水色→緑→黄→赤（従来と逆向き） |

※ 色相範囲が狭い（120 以下）と、どの色にも含まれないチャンネルはずらさずに元の色のまま残ります。

## アンインストール方法

1. YMM4 を起動して `ヘルプ(H)` > `その他` > `プラグインフォルダを開く` をクリックする。
2. YMM4 を終了する。
3. `DistortChroma` という名前のフォルダを削除する。

## 開発者向け：ビルドとリリース

- ローカルでは `Directory.Build.props` の `YMM4DirPath` に YMM4 のフォルダを指定してビルドします（シェーダーは Windows SDK の fxc.exe で自動コンパイルされます）。
- GitHub Actions が push・プルリクエストごとに YMM4 を取得してビルドし、`.ymme` と `.zip` をアーティファクトとして保存します。
- リリースするときは、`DistortChroma.csproj` の `Version` と、この Readme の「アップデート内容」を更新してから、Actions の「Build」ワークフローを「Run workflow」で `release` にチェックを入れて実行します（`v○.○.○` タグの push でもリリースされます）。
