DistortChroma  
製作者：panko200  
配布場所：https://github.com/DistortChroma

## 概要

YukkuriMovieMaker4 にて動作する映像エフェクトプラグインです。  
色ズレありVectorBlurらしいです。

## 使用方法

1. プラグインをインストールして YMM4 を起動する。
2. アイテムを追加し、映像エフェクトから、「ディストートクロマ」を適用する。
3. 任意の設定にすれば、動きます。

### 基準位置

色ズレをどこを基準に広げるかを指定します。

- **0%**（初期値）：元の位置から歪みの方向の片側へずれます（従来と同じ）。
- **50%**：元の位置を中心に両側へ広がるので、全体の位置がずれません。
- **100%**：歪みと逆の方向の片側へずれます。

### 色（収差の色の指定）

歪み量 0 の側から歪み最大の側へ向かって、指定した色相の範囲で色が割り当てられます。

- **色相**：開始色（歪み 0 の側の色）。0 で赤、120 で緑、240 で青。
- **色相範囲**：開始色から歪み最大側の色までの色相の幅。マイナスで逆回り。

| 色相 | 色相範囲 | 色の並び（歪み 0 → 最大） |
| --- | --- | --- |
| 0 | 240 | 赤→黄→緑→水色→青（従来と同じ、初期値） |
| 0 | 360 | 赤→…→青→紫→赤（虹色一周） |
| 300 | 180 | マゼンタ→赤→黄→緑 |
| 30 | 180 | オレンジ→黄→緑→水色 |
| 240 | -240 | 青→水色→緑→黄→赤（従来と逆向き） |

※ 色相範囲が狭い（120 以下）と、どの色にも含まれないチャンネルはずらさずに元の色のまま残ります。

## アンインストール方法

1. YMM4 を起動して `ヘルプ(H)` > `その他` > `プラグインフォルダを開く` をクリックする。
2. YMM4 を終了する。
3. `DistortChroma` という名前のフォルダを削除する。

## 注意点

OS : Windows11 (64bit)  
ゆっくりMovieMaker4 : v4.53.0.2  
にて動作確認をしています。
